### 🚀 [Try it live →](https://sadgemovies.vercel.app)

A movie discovery app built on the TMDB API. You can browse trending titles, search the catalog, and open trailers, cast and similar picks.

## ✨ Features
- Hero slideshow of popular movies (Swiper)
- Browse movies and TV by popular / top rated / upcoming / on-the-air
- Search across movies and TV by keyword
- Detail page with trailers, cast, and similar titles
- Paginated "Load more" grid via TMDB pagination
- Responsive layouts styled with Sass

## 🛠️ Tech Stack
- **Framework** — React 18 (Create React App)
- **Routing** — React Router v6
- **HTTP** — Axios
- **API** — The Movie DB (TMDB)
- **Styling** — Sass
- **Carousel** — Swiper

## 📖 Getting Started
```bash
npm install
npm start
```

### Environment variables
Create a `.env` file in the project root:

```
REACT_APP_TMDB_BASEURL=https://api.themoviedb.org/3/
REACT_APP_API_KEY=your_tmdb_api_key
```

Get a key from [themoviedb.org](https://www.themoviedb.org/settings/api).
